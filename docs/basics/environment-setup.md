## Overview

### Installing and configuring Node.js

Node.js is the JavaScript runtime used to build both frontend and backend applications. Below I document how to install Node.js and configure its environment variables.

### Using npm and package managers

npm is Node.js's package manager, widely used to manage JavaScript libraries and dependencies. In this section I mostly use npm to install and manage project dependencies, with Yarn and other package managers as points of comparison.

### Creating and managing projects

Project initialization, directory layout, dependency installation, and basic config files.

### Managing Node.js versions with nvm

nvm (Node Version Manager) is a tool for managing Node.js versions. Below I document installing, uninstalling, and switching Node.js versions with nvm — handy when different projects pin different runtime versions.

### Code editors and development tools

Choosing the right code editor and development tools improves productivity. I mainly use VS Code, Git, and similar tools; the relevant configuration items are listed below.

### ESLint and Prettier configuration

ESLint and Prettier are two essential tools for keeping code style consistent and improving code quality. Below I document how to install and configure ESLint and Prettier to automatically check and format code.
