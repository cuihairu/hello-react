# Outlook & The Future

Here I record React proposals and community developments, along with the impact they may have on upgrades and technology choices.

## Page Index

- [A Quick Look at New React Features](react-new-features.md) — candidate features for React 19/20: use, useOptimistic, useActionState, form Actions, document metadata
- [React Concurrent Mode Explained in Depth](react-concurrent-mode.md) — how concurrent rendering works, data fetching with Suspense, useDeferredValue, advanced startTransition patterns
- [The Future of React's Architecture](react-future.md) — the Compiler (React Forget), standardizing Server Components, the Offscreen API, resource preloading
- [The Evolution of the React Community & Ecosystem](react-community.md) — the RFC process, the core team's roadmap, adaptation progress of mainstream libraries, migration tooling
- [React Server Components (RSC)](react-server-components.md) — the RSC vs. Client Component boundary, the serialization protocol, streaming SSR, the Next.js/App Router implementation

## Reading Advice

- The notes here are based on React 18.3+ and Canary versions; some APIs may still be experimental
- I recommend reading alongside the official RFC repository (`github.com/reactjs/rfcs`) and the React blog
- Before adopting experimental features in a production project, weigh the risk your team can absorb and the rollback cost
