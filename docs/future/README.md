## 阅读建议

- 这里的记录基于 React 18.3+ 与 Canary 版本，部分 API 仍可能处于实验阶段
- 建议配合官方 RFC 仓库 (`github.com/reactjs/rfcs`) 与 React 博客同步阅读
- 生产项目引入实验性特性前，请评估团队承受风险与回滚成本
